# LESSON_FLOW.md — 9ステップ授業フロー

各ステップの「モデルへ渡す指示」と「完了条件」を定義する。
`lib/openai/steps.ts` にこの内容を実装する。

---

## 原則

**境界はコード、中身はモデル。**

| コードが決めること | モデルが決めること |
|---|---|
| いま何ステップ目か | どう説明するか |
| そのステップの完了条件を満たしたか | どんな例を出すか |
| どの教材が視野に入っているか | 生徒の発言にどう反応するか |
| 次にどこへ進むか | 次に何を聞き返すか |

この分離が、「AIが自分で授業を組み立てる自由さ」と「全員が同じ活動を通る公平性」を
両立させる唯一の方法。

**現在のステップの指示だけをモデルに渡す。** 9ステップ全部を1つの長い prompt に入れない。

---

## ステップ定義

### Step 1: レベル判定

現在のレベルを確認する。MVP では `students.current_level` を使い、実質スキップでよい。

- **指示**: 生徒に挨拶し、今日のテーマ（School Uniforms）を英語と日本語で伝える。
  「今日は制服について英語で意見を言えるようになります」と目標を示す。
- **完了条件**: 挨拶と目標提示が終わった
- **tool**: `mark_step_complete(1)`

### Step 2: 教材提示

- **指示**: 本文をゆっくり音読する。1文ずつ、生徒が追えるペースで。
  読み終えたら「分からない単語はありましたか」と聞く。日本語で答えてよいと伝える。
- **完了条件**: 本文を最後まで読み、生徒の質問に答えた
- **画面**: 左ペインに本文をハイライト表示（現在読んでいる文を強調）

### Step 3: 基礎学習

3つの小ステップに分ける。ここが最も時間がかかる。

**3a. 語彙**
- **指示**: 語彙リストの単語を1つずつ確認する。「What does *uniform* mean?」と聞き、
  生徒が答える。間違えたら意味を教えるのではなく、別の例文で使ってヒントにする。
  それでも分からなければ日本語で説明する。
- **完了条件**: 全語彙を1周した
- **tool**: つまずいた語は `flag_difficulty`

**3b. 文法**
- **指示**: 文法ポイントを本文中の実例で説明する。文法用語を並べない。
  「なぜここで `because` を使うと思う?」と考えさせてから説明する。
- **完了条件**: 全文法ポイントを説明した

**3c. ディクテーション**
- **指示**: ディクテーション文を **2回**読む。1回目は通常速度、2回目はゆっくり。
  生徒は画面の入力欄に書く。書き終わったら「書けました」と言ってもらう。
  **正解を言わない。** `record_answer` を呼んで次へ進む。
- **完了条件**: 全ディクテーション項目を1周した
- **tool**: `record_answer(item_id, answer_text, attempt_no)`
- **注意**: 採点しない。「合っています」「惜しい」も言わない

**3d. 英作文**
- **指示**: 和文を提示し、英語にしてもらう。画面の入力欄に書かせる。
  すぐに直さない。まず「自分でもう一度見直してみて」と促す。
- **完了条件**: 英作文課題を提出した
- **tool**: `record_answer`

### Step 4: 理解度確認

- **指示**: 本文の内容について3つ質問する。口頭で答えさせる。
  誤答時は「ヒント → 部分修正 → 正解」の順で支援する。いきなり正解を言わない。
- **完了条件**: 3問すべてに生徒が答えた（正誤は問わない）
- **tool**: `record_answer`、必要なら `flag_difficulty`

### Step 5: 論拠作成（日本語）

**このステップは日本語で行う。** 英語で考えさせない。

- **指示**: 「制服に賛成か反対か、どちらの立場にしますか」と日本語で聞く。
  立場が決まったら「なぜそう思いますか。理由を2つ、日本語で考えてください」と促す。
  1つ目が出たら「もう1つは?」と聞く。
  **2つ目が1つ目の言い換えになっていたら、違う角度を促す。**
  生徒の代わりに理由を考えない。行き詰まったら「朝の準備」「お金」「見た目」など
  観点だけを示す。
- **完了条件**: 立場が決まり、独立した理由が2つ出た
- **tool**: `record_argument(side, ja_text)` — 英語化する前に必ず記録

### Step 6: 英語化

- **指示**: 日本語の理由を英語にする。**先に生徒に試させる。**
  「これを英語で言うとどうなる?」と聞き、出てきた英語を土台に直す。
  全部言い直すのではなく、変える必要のある部分だけを示す。
  教材の文法ポイント（`I think ...` / `because ...`）を使うよう誘導する。
- **完了条件**: 2つの理由が英語になった
- **tool**: `record_argument(side, ja_text, en_text)` で英語版を追記

### Step 7: スピーキング

- **指示**: 画面を見ずに、自分の主張を声に出して言ってもらう。
  途中で止めない。最後まで言わせてから、1〜2点だけ指摘する。
  もう一度言ってもらう。2回目は改善点を褒める。
- **完了条件**: 主張を2回発話した
- **注意**: 発音を採点しない。指摘は「伝わりやすくする」観点で

### Step 8: AIディベート

レベルによって往復数を変える。

| レベル | 往復数 |
|---|---|
| beginner | 1往復（AIが1つ反論 → 生徒が応答） |
| intermediate | 2往復（反論 → 応答 → 再反論 → 再応答） |
| advanced | 3往復以上 |

- **指示**: 生徒の反対側に立つ。教材の `debate_tasks` にある反論を使う。
  短く、はっきり反論する（beginner なら1文）。
  生徒が黙り込んだら、10秒待ってから「日本語で言ってみて」と促し、
  それを英語にする支援をする。**生徒の代わりに答えない。**
- **完了条件**: 規定の往復数が終わった

### Step 9: 評価・振り返り

- **指示**: **点数を言わない。** 今日できたことを2つ、次に頑張ることを1つ、
  具体的に伝える。「よくできました」だけで終わらせない。
  最後に「お疲れさまでした」で締める。
- **完了条件**: 振り返りを伝えた
- **tool**: `mark_step_complete(9)`
- **その後**: ブラウザが `/api/lesson-sessions/:id/finish` を呼び、サーバー側で採点が走る

## ステップ遷移の実装

```ts
// lib/openai/steps.ts
export interface StepDefinition {
  no: number;
  key: string;
  nameJa: string;
  instruction: (m: Material) => string;   // 教材を埋め込んだ指示文
  tools: readonly string[];               // このステップで使える tool
  completion: string;                     // 完了条件（指示文に含める）
}

export const LESSON_STEPS: readonly StepDefinition[] = [ /* ... */ ];
```

遷移時の処理：

```
mark_step_complete(n) をブラウザが受信
   ↓
POST /api/results/step { lessonSessionId, stepNo: n }
   ↓
サーバー: current_step === n を検証
   ↓  違う → 警告ログ。current_step は動かさない。{ ok:false, current: X } を返す
current_step = n + 1
   ↓
ブラウザへ { ok: true, nextStep: n+1, instructions: "..." }
   ↓
ブラウザが session.update で instructions を差し替え
```

## 時間配分の目安

1コマ50分での想定。**実測して調整する前提。**

| Step | 目安 |
|---|---|
| 1-2 | 5分 |
| 3 (語彙・文法・ディクテーション・英作文) | 20分 |
| 4 | 5分 |
| 5-6 | 10分 |
| 7 | 3分 |
| 8 | 5分 |
| 9 | 2分 |

**おそらく50分に収まらない。** Step 1-4 と Step 5-9 で2コマに分割する案を
実測後に検討すること。分割する場合、`lesson_sessions` を跨いで再開できる必要がある。

## MVPでの縮小版

最初の実装では Step 3c（ディクテーション）→ Step 5 → Step 6 → Step 8 だけを通す。
語彙・文法・理解度確認は後から足す。

「音声往復 → 教材注入 → 記録1件」を縦に貫通させるのが先。
